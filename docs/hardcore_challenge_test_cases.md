## 2. 建议补充的测试用例

### 2.1 交互限制补充

| 用例 | 优先级 | 说明 |
|------|--------|------|
| 硬核角色尝试发送邮件，验证无法发送 | 中 | 已有 `CanSendMail` hook，当前用例未覆盖 |
| 硬核角色尝试进入竞技场，验证无法进入 | 中 | 已有 `CanJoinInArenaQueue` hook |
| 非硬核角色向硬核角色发起交易，验证交易无法建立 | 高 | 需双向验证：发起方/接受方任一为硬核即应拦截 |
| 硬核角色已加入队伍后登出再登入，验证是否自动退出队伍 | 中 | 当前只有邀请/接受拦截，已入队场景未处理 |
| 硬核角色通过集合石/副本门直接进入副本，验证是否允许 | 中 | `CanJoinLfg` 只拦随机本排队，不拦物理进入 |
| 硬核角色使用公会银行、个人银行，验证是否允许 | 低 | 当前未限制，需确认业务规则 |
| 硬核角色在拍卖行购买/出售物品，验证是否允许 | 低 | 当前未限制，需确认业务规则 |

## 3. 异常用例初步分析

| 用例 | 可能原因 | 建议 |
|------|----------|------|
| 无法交易 | 此前未实现 `CanInitTrade` hook | 本轮已新增，部署后重测 |
| 无法排随机本 | 可能只拦截了 NPC 对话入口，未拦截命令/界面入口 | 检查 `CanJoinLfg` 调用路径 |
| 无法进入战场 | 可能只拦截了战场军官对话入口 | 检查 `CanJoinInBattlegroundQueue` 调用路径 |
| 无法装备白色系以上 | 此前未实现 | 本轮已新增，部署后重测 |
| 无法使用附魔 | 当前策略为“仅允许萨满武器附魔”，若业务要求全部附魔禁用则需调整 | 确认需求 |
| 经验合剂不能使用 | 未实现 | 建议新增物品 use hook 或 aura 检测 |
| 萨满石化武器可用 | 需确认 spell id 1669 是否为当前版本的石化武器 | 核对 spell id |
| 60/70 成功通告与奖励 | 依赖 `challenge_modes.conf` 的 title map 配置 | 检查配置是否有 60/70 映射 |
| 退出后无奖励 | 需先确保退出机制本身生效 | 测试 Token 移除场景 |

## 4. 待确认规则

1. **“无法使用附魔”**：是全部附魔禁用，还是仅允许萨满武器附魔？
2. **“白色系以上”**：是否包含白色？当前实现允许白色/灰色，拦截绿色及以上。
3. **经验合剂范围**：是否包含所有经验加成类消耗品、药水、食物？
4. **组队场景**：是仅禁止组队邀请，还是连已存在的队伍也要解散？
5. **副本进入**：是否禁止通过副本门/集合石进入副本？
6. **奖励形式**：title、物品、金币、技能等，需在 `challenge_modes.conf` 中配置。
